# Baseline de Refinamento de Ideia — EXP-M05.4-IDEA-01-COND-A

## Ideia Original
> Um aplicativo de cronômetro pomodoro minimalista para desktop que bloqueia notificações de outros apps durante os blocos de foco de 25 minutos.

## Resumo do Modelo
Um aplicativo de cronômetro Pomodoro minimalista para desktop que bloqueia notificações de outros apps durante blocos de foco de 25 minutos.

## Versão Refinada
Um aplicativo Pomodoro multiplataforma (Windows, macOS, Linux) com UI minimalista, timer configurável, modo de foco que silencia ou pausa notificações do sistema e de apps selecionados, opções de sons ambientes, integração opcional com ferramentas de tarefas (Todoist, Trello) e relatórios de produtividade. O usuário pode escolher entre bloqueio total, silenciamento ou apenas ocultação de notificações, além de definir durações personalizadas e ciclos de descanso. O código é open‑source e oferece extensões para personalização avançada.

## Pontos Fortes e Fracos
- **Fortes:** Foco intenso ao eliminar distrações, Interface simples e fácil de usar, Baseado em técnica comprovada de produtividade, Baixo consumo de recursos
- **Fracos:** Disponível apenas para desktop, excluindo usuários mobile, Bloqueio de notificações pode ser percebido como invasivo, Pouca personalização de tempos, sons e temas, Integração limitada com outros sistemas de gestão de tarefas

## Próximos Passos
Realizar pesquisa de mercado para validar demanda e identificar concorrentes, Definir requisitos funcionais detalhados (bloqueio de notificações por SO, integrações, personalizações), Escolher stack tecnológica (ex.: Tauri + Rust para leveza ou Electron), Desenvolver protótipo de UI/UX e testar com usuários reais, Implementar módulo de controle de notificações para cada sistema operacional, Adicionar integração opcional com APIs de gestão de tarefas, Criar sistema de coleta de métricas de uso e feedback, Planejar lançamento de versão beta fechado e iterar com base no retorno dos usuários
