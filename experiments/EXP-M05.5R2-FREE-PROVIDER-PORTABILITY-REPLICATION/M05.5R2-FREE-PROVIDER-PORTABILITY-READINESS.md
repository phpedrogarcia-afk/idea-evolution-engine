## 3. Auditoria Forense ao Vivo dos Provedores Candidatos

Foi realizada uma investigação ao vivo utilizando endpoints públicos de metadados (sem chamadas de inferência não autorizadas) e documentação técnica oficial atualizada:

### 3.1. OpenRouter (`openai/gpt-oss-120b:free` vs `openai/gpt-oss-120b`)
- **Consulta ao Endpoint de Metadados:** `GET https://openrouter.ai/api/v1/models/openai/gpt-oss-120b:free/endpoints`
- **Resultado Observado:** HTTP 200 OK, com payload:
  ```json
  {
    "data": {
      "id": "openai/gpt-oss-120b:free",
      "name": "OpenAI: gpt-oss-120b",
      "architecture": { "tokenizer": "GPT", "modality": "text->text" },
      "endpoints": []
    }
  }
  ```
- **Fato Técnico:** O slug `:free` existe no catálogo histórico do OpenRouter, mas **possui zero endpoints ativos no momento (`endpoints: []`)**. Nenhuma infraestrutura parceira está oferecendo capacidade gratuita para esse modelo no OpenRouter hoje.
- **Variante Ativa no OpenRouter:** O modelo ativo é `openai/gpt-oss-120b` (sem o sufixo `:free`), servido por 21 provedores parceiros (AkashML, CoreWeave, DeepInfra, Together, Cerebras, etc.), porém **todos são tarifados** (preço mínimo: \$0,03 / \$0,17 por milhão de tokens).
- **Invariante de Custo:** Chamar `openai/gpt-oss-120b:free` resultaria em erro 404 (sem backends disponíveis); chamar `openai/gpt-oss-120b` violaria a política `FREE_ONLY = TRUE`.
- **Chave de API:** A variável de ambiente `OPENROUTER_API_KEY` não está presente no ambiente de execução.

### 3.2. NVIDIA Build / NIM (`build.nvidia.com` / `integrate.api.nvidia.com`)
- **Documentação Oficial:** O endpoint de protótipo gratuito para `openai/gpt-oss-120b` registrava data de depreciação programada para **2 de setembro de 2026** (data corrente).
- **Veredito:** Inadmissível devido à descontinuação do endpoint hospedado.

### 3.3. SambaNova Cloud (`docs.sambanova.ai`)
- **Documentação Oficial:** No guia de Function Calling e Structured Outputs, a documentação oficial da SambaNova explicita:
  > *"false is currently the default and the only value with active enforcement. Setting strict: true is accepted without error but may not currently result in additional behavioral changes."*
- **Veredito:** Inadmissível por regra expressa da Seção 4 da diretriz (`strict: true` sem imposição ativa).

### 3.4. Hugging Face Serverless Inference
- O serviço gratuito Serverless Inference API da Hugging Face possui limite estrito de tamanho de modelo (< 10 GB).
- Modelos de 120 bilhões de parâmetros exigem *Dedicated Inference Endpoints* (instâncias pagas de GPU a \$2,00–\$4,50/hora).
- **Veredito:** Inadmissível sob a política de custo zero.

### 3.5. Cerebras Cloud (`docs.cerebras.ai`)
- Oferece velocidade e suporte a JSON schema estrito, mas opera exclusivamente com créditos promocionais temporários de teste (\$5 expirando em 30 dias), sem camada gratuita duradoura e auto-renovável.
- **Veredito:** Inadmissível perante a regra `TRIAL_CREDIT_DEPENDENCY_AS_PRIMARY_STRATEGY = NO`.

### 3.6. Cloudflare Workers AI (`@cf/openai/gpt-oss-120b`)
- Endpoint tarifado por token (\$0,350 / \$0,750 por milhão de tokens). A cota diária gratuita de "neurons" é insuficiente para suportar a carga de um modelo de 120B.
- **Veredito:** Inadmissível por não ser gratuito.

### 3.7. Api.Airforce
- Gateway/proxy não-oficial com roteamento dinâmico entre múltiplos provedores upstream não identificados. Não permite fixação de backend (`provider.only`) e mascara a identidade do hardware e da infraestrutura, violando a integridade metodológica de replicação.
- **Veredito:** Inadmissível por ausência de garantia de estabilidade e proveniência.

## 6. Parecer Epistemológico e Próximos Passos Recomendados

A conclusão inequívoca da auditoria ao vivo é que **não existe atualmente nenhuma infraestrutura de inferência em nuvem ativa que sirva o modelo `openai/gpt-oss-120b` com validação estrita de JSON Schema a custo estritamente zero**.

Para destravar a conclusão do programa de replicação do M05.5, submetem-se ao supervisor três alternativas metodologicamente limpas:

1. **Opção A — Bounded Micro-Budget no OpenRouter (Recomendada):**
   - No OpenRouter, o modelo `openai/gpt-oss-120b` é servido por provedores robustos com `structured_outputs` ativo (ex: CoreWeave ou AkashML) a \$0,03 por milhão de tokens de entrada e \$0,17 de saída.
   - O experimento inteiro de 24 células consome aproximadamente 100.000 tokens totais, o que representa um custo real inferior a **\$0,02 (dois centavos de dólar)**.
   - Caso o supervisor aprove formalmente o uso de uma chave com saldo pré-pago limitado e teto de gastos estrito (\$1,00 de limite fail-closed), a replicação pode ser executada imediatamente via OpenRouter com fixação de backend (`provider.only = ["CoreWeave"]`).
2. **Opção B — Aguardar Restauração de Endpoint Gratuito no OpenRouter:**
   - O slug `openai/gpt-oss-120b:free` existe na especificação do OpenRouter, aguardando que um patrocinador ou datacenter volte a alocar capacidade gratuita. O projeto aguardaria a reativação desse endpoint.
3. **Opção C — Portabilidade de Modelo com Camada Gratuita Duradoura:**
   - Caso a regra `FREE_ONLY = TRUE` seja absolutamente inegociável, seria necessário submeter ao supervisor uma emenda de desenho para utilizar outro modelo de alto raciocínio que possua endpoint gratuito ativo no OpenRouter com suporte a structured outputs (ex: `google/gemma-4-31b-it:free` ou `nvidia/nemotron-3-super-120b-a12b:free`), registrando a mudança explícita de modelo.
