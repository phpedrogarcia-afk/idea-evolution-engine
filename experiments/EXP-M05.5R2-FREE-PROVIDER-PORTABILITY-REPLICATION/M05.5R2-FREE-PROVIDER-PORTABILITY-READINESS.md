## 4. Auditoria Técnica ao Vivo do NVIDIA NIM

### 4.1. Endpoint e Identidade do Modelo
- **Base URL Oficial:** `https://integrate.api.nvidia.com/v1`
- **Model ID Exato:** `openai/gpt-oss-120b`
- **Formato de Chamada:** Compatível com OpenAI Chat Completions (`/chat/completions`) e Responses API (`/responses`).

### 4.2. Suporte a Saída Estruturada e JSON Schema
- A documentação oficial da NVIDIA NIM para LLMs recomenda o mecanismo de decodificação guiada **`guided_json`** (baseado no motor de alto desempenho `xgrammar`), que aplica uma máscara de tokens em cada passo da geração:
  ```json
  {
    "model": "openai/gpt-oss-120b",
    "messages": [...],
    "temperature": 0.3,
    "max_tokens": 2048,
    "guided_json": { ... schema lógico Pydantic ... },
    "extra_body": {
      "nvext": {
        "guided_json": { ... schema lógico Pydantic ... }
      }
    }
  }
  ```
- O endpoint também suporta o envelope padrão OpenAI:
  ```json
  "response_format": {
    "type": "json_schema",
    "json_schema": {
      "name": "SchemaName",
      "strict": true,
      "schema": { ... schema lógico Pydantic ... }
    }
  }
  ```
- **Equivalência Epistemológica:** O schema lógico gerado a partir dos modelos Pydantic (`model_json_schema()`) é transmitido intacto, preservando 100% dos nomes de propriedades, tipos, arrays, campos obrigatórios (`required`) e proibição de campos adicionais (`additionalProperties: false`).
- A adaptação de sintaxe para `guided_json` constitui **TRANSPORT_ADAPTATION** e não **TREATMENT_SEMANTIC_CHANGE**.

### 4.3. Limites e Controle de Capacidade do Provedor
- **Custo de Inferência:** Zero (gratuito para desenvolvedores através do portal Build).
- **Mecanismo de Limite:** A NVIDIA fez a transição do modelo antigo de "créditos de API" para tetos de taxa de requisição (**RPM**).
- **Baseline de Rate Limit:** 40 requisições por minuto (RPM) por conta padrão.
- **Prevenção de Paid Fallback:** O endpoint `integrate.api.nvidia.com` não possui cobrança por token e não migra automaticamente para cartões de crédito. Qualquer desvio de URL base é bloqueado fail-closed pelo adapter local (`FAIL_CLOSED_PAID_ROUTING_GUARD`).
