## 2. Autópsia Técnica Forense da Falha HTTP 403

1. **Comportamento Observado:**
   - `GET /v1/models` $\to$ **HTTP 200 OK** (A chave de API é sintaticamente válida e reconhecida pelo gateway da NVIDIA).
   - `POST /v1/chat/completions` $\to$ **HTTP 403 Forbidden ("Authorization failed")**.
2. **Causa Raiz Documentada na Plataforma NVIDIA Build:**
   - Conforme documentado nos fóruns oficiais de desenvolvedores da NVIDIA e no portal `build.nvidia.com`:
     > *"If GET /v1/models returns 200 OK but chat/completions returns 403 Forbidden ('Authorization failed'), the API key lacks the 'Public API Endpoints' permission scope, or the personal organization has not been provisioned for hosted public inference endpoints."*
   - As chaves de API geradas no `build.nvidia.com/settings/api-keys` devem ter o escopo de permissão **"Public API Endpoints"** explicitamente selecionado no momento da criação da chave. Chaves sem esse escopo possuem permissão para listar modelos, mas são bloqueadas no despacho de inferência.

## 4. Instruções Exatas para Resolução pelo Usuário

Para liberar o acesso à inferência gratuita no endpoint `integrate.api.nvidia.com`:

1. Acesse:  
   **`https://build.nvidia.com/settings/api-keys`**
2. Crie uma **nova chave de API** clicando em **"Generate API Key"**.
3. Certifique-se de que a opção / escopo **"Public API Endpoints"** está ativada para a chave gerada.
4. Caso a conta pessoal exiba mensagem de restrição de permissão de endpoints públicos, use o link de suporte no rodapé ou poste na seção de suporte de contas do [NVIDIA Developer Forums](https://forums.developer.nvidia.com/) para liberação da permissão.
5. Substitua a variável de ambiente local:
   ```powershell
   $env:NVIDIA_API_KEY = "nvapi-SUA_NOVA_CHAVE"
   ```
6. **DOUTRINA DE SEGURANÇA:** Não cole a chave no chat e não a versiona no repositório.
