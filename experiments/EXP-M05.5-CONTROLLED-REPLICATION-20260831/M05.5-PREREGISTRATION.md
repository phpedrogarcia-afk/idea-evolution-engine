## 7. Critérios Pré-Registrados de Replicação

### PRIMARY_REPLICATION
- **PASS** se: Condição C obtém o maior total ordinal, sem empate em 1º.
- **INCONCLUSIVE** se: Condição C empata com B no total ordinal.
- **NOT_REPLICATED** se: Condição B supera Condição C no total ordinal.

### CONVERGENT_REPLICATION
- **PASS** se: Condição C também tem (a) maior pontuação secundária agregada E (b) maior ou empatada contagem de CONTINUE.

### FULL_PATTERN_REPLICATION
- **PASS** se: PRIMARY_REPLICATION = PASS **E** CONVERGENT_REPLICATION = PASS **E** C > B em Controle de Premissas **E** C > B em Moderação Apropriada **E** C usa substancialmente menos chamadas que B.
